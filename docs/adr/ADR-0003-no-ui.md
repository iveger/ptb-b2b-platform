# ADR-0003 — Отсутствие пользовательского UI

## Статус
Принято

## Контекст
Платформа предназначена для B2B-интеграций и автоматизаций.

## Решение
Платформа не предоставляет пользовательский интерфейс.
Взаимодействие осуществляется через API.

## Обоснование
- снижение сложности
- фокус на надёжности backend
- UI остаётся ответственностью клиентов

## Последствия
- API-first подход
- необходимость качественной документации
