# ADR-0001 — Использование монорепозитория

## Статус
Принято

## Контекст
Проект ptb-b2b-platform представляет собой платформу,
включающую backend, интеграции, AI-компоненты и инфраструктурные конфигурации.

На старте рассматривались два подхода:
- несколько независимых репозиториев
- единый монорепозиторий

## Решение
Принято решение использовать единый монорепозиторий (monorepo)
для хранения всего кода и документации платформы.

## Обоснование
- единый контекст для архитектуры и документации
- упрощённое управление версиями и зависимостями
- отсутствие преждевременной микросервисной сложности
- прозрачная эволюция платформы как целого продукта

## Последствия
Положительные:
- проще контролировать архитектурную целостность
- документация и код развиваются синхронно

Ограничения:
- рост репозитория со временем
- необходимость дисциплины в структуре каталогов

## Альтернативы
Несколько репозиториев были отвергнуты из-за:
- высокой координационной сложности
- риска рассинхронизации документации и кода
- отсутствия реальной необходимости на ранних этапах
