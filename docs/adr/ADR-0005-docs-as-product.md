# ADR-0005 — Документация как часть продукта

## Статус
Принято

## Контекст
Без актуальной документации платформа теряет управляемость.

## Решение
Документация рассматривается как часть продукта.

## Обоснование
- снижение bus factor
- ускорение онбординга
- сохранение архитектурного контекста

## Последствия
- изменения без обновления docs считаются незавершёнными
