# ADR-0002 — Backend как источник истины

## Статус
Принято

## Контекст
Платформа взаимодействует с внешними системами,
AI-компонентами и интеграциями.

Без чёткого определения источника истины возникает риск:
- дублирования логики
- расхождения данных
- неконтролируемых побочных эффектов

## Решение
Backend платформы является единственным источником истины
для бизнес-логики, данных и правил обработки.

Все внешние компоненты (интеграции, AI, автоматизации)
работают исключительно через backend API.

## Обоснование
- централизованный контроль бизнес-правил
- предсказуемость поведения системы
- упрощение аудита и логирования
- снижение риска неконтролируемых изменений

## Последствия
Положительные:
- единая точка ответственности
- проще тестировать и сопровождать систему

Ограничения:
- backend становится критически важным компонентом
- требуется высокая надёжность и наблюдаемость

## Альтернативы
Распределённая бизнес-логика была отвергнута из-за:
- сложности поддержки
- роста архитектурного долга
- трудностей в обеспечении целостности данных
