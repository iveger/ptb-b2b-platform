# Architectural Decision Records

Этот каталог содержит Architectural Decision Records (ADR) проекта ptb-b2b-platform.

ADR используются для:
- фиксации архитектурных решений
- сохранения контекста принятых выборов
- предотвращения повторных обсуждений одних и тех же вопросов
- поддержки долгосрочной эволюции платформы

Каждый ADR описывает одно конкретное решение и его последствия.
Изменение архитектурных принципов допускается только через новый ADR.
