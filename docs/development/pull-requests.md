# Pull Requests

Pull Request является основной единицей изменения платформы.

## Общие требования

- каждый PR решает одну задачу
- PR должен иметь понятное название
- прямые коммиты в main запрещены

## Содержание PR

PR должен содержать:
- описание цели изменений
- краткое объяснение архитектурных решений
- ссылки на связанные ADR (если применимо)

## Проверки перед merge

Перед merge PR должен:
- успешно проходить CI (если настроен)
- не нарушать существующие ADR
- обновлять документацию при необходимости

## Размер PR

- предпочтительны небольшие PR
- большие изменения должны быть логически разбиты
