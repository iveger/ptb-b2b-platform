# Definition of Done

Изменение считается завершённым, если выполнены все условия ниже.

## Обязательные критерии

- код компилируется и запускается
- бизнес-логика соответствует описанию задачи
- отсутствуют очевидные технические долги
- документация обновлена при необходимости
- изменения внесены через Pull Request

## Архитектурные требования

- соблюдены границы модулей
- не нарушены существующие ADR
- новые архитектурные решения зафиксированы через ADR

## Качество

- код читаем и поддерживаем
- отсутствуют временные решения ("TODO на потом")
